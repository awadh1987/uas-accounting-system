إغلاق الفترات والقطفات (Period Locking)

التوقيت المستخدم والدور نوع الحدث التفاصيل والبيان بصمة التحقق (Hash)

مركز تطبيق الجوال (Android APK / iOS IPA / Installable PWA)

تصميم متجاوب بالكامل مع شاشات الهواتف الذكية + شريط تنقل سفلي + زر إدخال ميداني سريع + بناء حزم Capacitor و Expo

1. تطبيق ويب تقدمي قابل للتثبيت (PWA)

يدعم التثبيت المباشر على شاشة الهاتف الرئيسية (Add to Home Screen) على أندرويد و iOS بدون متجر، مع عمل كامل بدون إنترنت في المزارع.

2. حزمة أندرويد و iOS عبر Capacitor

تحويل نفس واجهة النظام إلى تطبيق أصلي (Native APK / AAB & iOS IPA) مع وصول مباشر للكاميرا (مسح QR)، والطباعة الحرارية Bluetooth.

3. تطبيق React Native (Expo SQLite)

بنية Local-First بقاعدة بيانات SQLite مدمجة داخل الهاتف للمحاسبين الميدانيين مع مزامنة تلقائية مع Supabase PostgreSQL.

# خطوات استخراج ملف APK للأندرويد و IPA للآيفون عبر Capacitor:
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap init "UAS Accounting" "com.uas.accounting" --web-dir=out
npm run build && npx cap add android && npx cap add ios
npx cap sync && npx cap open android

مزايا واجهة الجوال المدمجة في هذه النسخة:

  • ✅ شريط تنقل سفلي ثابت (Bottom App Bar): وصول بيد واحدة لأهم 5 أقسام رئيسية.
  • ✅ زر الإدخال السريع العائم (+ FAB): تسجيل عملية بيع أو مصروف وقود أو دفعة عميل في 5 ثوانٍ من المزرعة.
  • ✅ توافق اللمس والشاشات الصغيرة: أزرار وحقول مكبرة ومحاكي شاشة هاتف ذكي مدمج (412px).
  • ✅ مشاركة الفواتير عبر واتساب و QR: إرسال السند مباشرة لتطبيق واتساب على الجوال.

⚡ إدخال ميداني سريع (تطبيق الجوال)
